# 图标策略

站点的图标有四种来源，按离真实品牌的远近排序。

| 形式 | 什么时候用 | 写法 |
|---|---|---|
| `logo` | 能拿到官方图标文件 | `logo(asset("/brand/x.png"), "light", "fill")` |
| `brand` | Reicon Brands 里有这个品牌 | `brand(Github)` |
| `glyph` | 没有品牌标，用 Reicon 图标表意 | `glyph(Bolt)` |
| `letter` | 用户自建又没取到 favicon | 自动生成，取名称首字 |

## 自定义站点的图标

添加或编辑站点时，对话框把每个来源对这个地址实际返回的图标并排摆出来，看着选：

| 来源 | 地址 | 说明 |
|---|---|---|
| 浏览器缓存 | 站点自己的 `apple-touch-icon.png`，再试 `favicon.ico` | 不经第三方；去过的站点直接从浏览器缓存出 |
| Google | `t2.gstatic.cn/faviconV2` | 国内节点；不认识的站点会回 16 像素地球，按“没有”处理 |
| favicon.is | `favicon.is/<host>?larger=true` | 尺寸较大 |
| 上传 | 本地文件，缩到 128 像素存成 WebP | 存在这台设备的 localStorage，几 KB |
| 图标地址 | 手填 | |

图标服务只拿到站点的 origin，路径和参数不外传。新站点在用户动手前自动跟着最好的结果走，
优先级是浏览器缓存、Google、favicon.is，排在前面的都回话了才定。出厂站点多一个“内置”，选它就恢复原图标。

网页读不到浏览器扩展那种图标缓存，所以“浏览器缓存”指的是 HTTP 缓存：直接请求站点自己的文件，
本机访问过就不再走网络。

## 异形图标的底色

图标能读到像素时（上传的、同源的），选定那一刻量一次形状，存进站点数据，之后渲染不再计算：

- 不透明的方形图标自带底色，`fill` 铺满底板。
- 边缘透明（外圈 2 像素里至少 40% 透明，且不透明像素不超过 90%）的，加一块取自图标主色的浅色底；
  浅色底托不住时（白色 logo），换成主色压到深色底板方向的深色底。对比度下限 1.6:1。
- 读不到像素的（图标服务都不发 CORS 头），保持白色底板。

用户可以关掉底色，或从主色、次色、白、深色里挑一个，也能自定义颜色。判断规则和阈值参考 lumno 的
shortcut icon plate，代码是这边重写的。

## 加载与缓存

- 页面空闲时把所有 logo 预取并解码，切分类、翻页时从内存出图。
- 加载失败的地址记三天（`yourtj-nav-icon-miss`），这期间直接画兜底图标，不再请求。离线时的失败不记。
- 第一次加载的图标淡入 160 毫秒；已经在内存里的直接出现，不做动画。

## 底板

每块底板都是白的，色值 `oklch(0.985 0.002 250)`，明暗两种模式一样。真实 logo 文件本来就画在白底上，
底板跟着主题变色时，同一个网格会看起来像两套东西。

底板统一加 `overflow: hidden` 和同心圆角。`fill` 类图标撑满，`inset` 类留白居中。

图标颜色分两种处理：

- 品牌图标保持原色。
- 字形图标按名称哈希到 8 个马卡龙色相之一，每个色相单独定亮度。

| hue | 24 | 52 | 92 | 146 | 192 | 228 | 272 | 320 |
|---|---|---|---|---|---|---|---|---|
| L | .568 | .564 | .551 | .539 | .512 | .526 | .560 | .568 |

不用真正的粉彩，是因为粉彩的 L 在 0.8 左右，放白底上只有 2:1，达不到 WCAG。
这里固定 chroma 0.16，逐色相压亮度，18 个图标实测最低 4.56:1。
同一个图标每次打开都是同一个颜色。

## 板块属性只在一处推导

`plateProps(mark)`（在 `src/components/Mark.tsx`）返回 `data-chip`、`data-fit` 和底色变量 `--plate`。
网格、置顶栏、最近访问和选择器都展开它，不要手写这两个属性。

漏一次 `data-fit="fill"`，`Mark` 里的 `<img width={64} height={64}>` 就没有 CSS 覆盖，
会以 64 像素塞进 44 像素的格子溢出来。

## 素材落地

- 从别处恢复图标时先确认真实格式。原站可能把 PNG 挂在 `.svg` 路径上，直接按扩展名落盘，
  服务器会以 `image/svg+xml` 发出，然后渲染失败。用 `file` 或 PIL 验一下再改名。
- 白色图标铺在白底板上等于隐形。取不透明像素的平均色，接近 255,255,255 就换方案，
  改用 Reicon Brands 的矢量标，或者反色。
- 图标加载失败时，`Mark` 退回一个链接图标，不留破图框。
